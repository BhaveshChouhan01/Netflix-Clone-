# Netflix Clone 🎥

A responsive front-end clone of the Netflix homepage built with **HTML5** and **CSS3**. Perfect for showcasing modern web layout techniques, hover effects, and mobile-first design.

## Features ✨
- **Pixel-Perfect Design**: Replicates Netflix's iconic hero section, navbar, and card layouts.
- **Responsive UI**: Works flawlessly on mobile, tablet, and desktop screens.
- **Font Awesome Integration**: Icons for navigation and CTAs.
